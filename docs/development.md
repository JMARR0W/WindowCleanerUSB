# Development

## First milestone

Get the repository building and the launcher reporting:

- manufacturer
- model
- architecture
- firmware mode
- Secure Boot state
- RAM
- disk inventory

No disk modifications should occur.

## Second milestone

Build a minimal WinPE image and prove that the machine can boot it in a VM.

## Third milestone

Implement deterministic disk identification and a dry-run deployment mode.

## Fourth milestone

Implement Windows image application and unattended configuration.

## Fifth milestone

Add hardware-specific profiles and drivers.
